# 双语对照翻译（dual-translate）

给 [SillyTavern（酒馆）](https://github.com/SillyTavern/SillyTavern) 和 TauriTavern 用的翻译扩展：把 AI 的外文消息**逐段翻译成中文，译文贴在每段原文下面**，对照着看；输入框里还有一个按钮，可以把你写的中文翻成英语 / 日语再发出去。

- 两个翻译源，随时切换：**DeepSeek**（或其他 OpenAI 兼容接口）、**谷歌翻译**（不需要 API Key）
- 译文带缓存：翻过的段落不会再花一次钱、再发一次请求，刷新页面也还在
- 手机和电脑都能用，设置面板和按钮针对触屏做了适配

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 逐段对照 | 每段原文后面紧跟它的译文；也可以切成「整块翻译」，把译文集中放在消息底部 |
| 自动翻译 | 可选：AI 回复完自动翻译 |
| 翻译全部 | 一键翻译当前聊天里所有 AI 消息，翻过的直接用缓存，可随时中途停止 |
| 译文缓存 | 按「翻译源 + 目标语言 + 段落内容」缓存；只把没翻过的段落发出去 |
| 编辑 / 重新生成 | 原文改了、滑动换了一条回复，旧译文自动作废，只重新翻改变的那几段 |
| 保留格式 | `*动作描写*`、`**强调**`、引号、`{{user}}` 之类的标记原样保留 |
| 输入框翻译 | 输入框旁的按钮，把你写的中文翻成英语 / 日语（固定使用 DeepSeek） |
| 清楚的报错 | 没填 Key、网络不通、需要梯子、超时……都会直接告诉你原因，并给出「重试」按钮，不会一直卡在「翻译中」 |

## 安装

### 方法一：用仓库地址安装（推荐）

1. 打开酒馆，点顶部的 **扩展（积木图标）** → **安装扩展**
2. 填入本仓库地址：

   ```
   https://github.com/<你的用户名>/dual-translate
   ```

3. 点安装，安装完成后刷新页面
4. 在扩展设置里能看到 **🌐 双语对照翻译**，就装好了

TauriTavern 的安装方式和酒馆一样。

### 方法二：手动安装

把整个 `dual-translate` 文件夹（里面要有 `manifest.json`、`index.js`、`style.css` 和 `lib` 文件夹）复制到酒馆的第三方扩展目录：

```
<酒馆数据目录>/extensions/dual-translate/
```

酒馆版本不同，这个目录的位置会有差别（有的在 `public/scripts/extensions/third-party/`），以你用的版本为准。复制完刷新页面。

## 使用

- 每条消息的按钮栏里有一个 **翻译图标**：点一下翻译这条消息，再点一下隐藏 / 显示译文
- 设置面板里的 **自动翻译 AI 新消息** 打开后，AI 回复完会自动翻译
- **显示模式**：逐段对照 / 整块翻译
- **翻译语言组合**：英语 ⇄ 简体中文、日语 ⇄ 简体中文，也可以自定义目标语言
- 输入框旁边的翻译图标：先在输入框里写中文，点一下，输入框里的文字就会变成译文，检查后再发送

## 设置翻译源

在设置面板的 **翻译源** 下拉框里选择。

### 用 DeepSeek

1. 到 [DeepSeek 开放平台](https://platform.deepseek.com/) 注册并创建 API Key
2. 翻译源选 **DeepSeek**，然后填写：

   | 项目 | 填什么 |
   | --- | --- |
   | API 地址 | `https://api.deepseek.com/v1` |
   | API Key | 你自己的 Key（`sk-` 开头） |
   | 模型 | `deepseek-chat` |

3. 随便翻译一条消息试试

> 不只是 DeepSeek：任何 **OpenAI 兼容** 的接口都能用（比如 SiliconFlow 等）。把 API 地址、Key、模型名换成对应服务的就行，API 地址要填到 `/v1`。

### 用谷歌翻译

1. 翻译源选 **谷歌翻译**
2. 不需要填任何 Key
3. 点 **🔌 测试谷歌连接**，提示「连接正常」就可以用了（提示里会写明这次走的是哪条路线）

**注意：谷歌翻译需要这台设备能访问谷歌**，国内网络通常需要开梯子 / VPN。

谷歌有两条路线，在设置里的 **谷歌连接方式** 选：

| 选项 | 怎么走 | 适合 |
| --- | --- | --- |
| 自动（默认） | 先试浏览器直连；不通就自动改走酒馆后端，并记住哪条通 | 大多数情况 |
| 只用浏览器直连 | 浏览器 / App 直接请求谷歌，用的是它自己的网络（系统代理、VPN 都管用） | 酒馆后端连不上谷歌，但浏览器能上 |
| 只用酒馆后端 | 请求交给酒馆后端（Node 进程）去访问谷歌 | 浏览器直连被限制，但后端能连谷歌 |

> 酒馆后端**不读系统代理**。电脑上开了梯子、浏览器能打开谷歌，不代表酒馆后端也能：它需要在酒馆的 `config.yaml` 里配置 `requestProxy`（并重启酒馆），旧版酒馆里谷歌翻译甚至会忽略这项设置。遇到这种情况，用默认的「自动」或「只用浏览器直连」即可，不用改酒馆。

两条路线都不通时，错误提示里会同时写出两条路线各自的原因，不会无限卡住。

选谷歌时，DeepSeek 的设置会折叠起来，因为谷歌用不到它们；但输入框旁的翻译按钮**仍然固定使用 DeepSeek**，要用的话需要展开「输入框翻译所用的 DeepSeek 设置」填好 Key。

## 翻译缓存

- 缓存的单位是**段落**，键 = 翻译源 + 目标语言 + 段落内容的哈希。同一段话换了翻译源或目标语言，会各自翻一次；段落内容变了，自然就是新的键，旧译文不会错位。
- 一条长消息只改了其中一段（或新来了几段），只有这几段会发给翻译源。
- 缓存存在浏览器 / WebView 的本地存储（localStorage）里，**刷新页面后还在**。
- 有上限：最多保留约 5000 段、约 120 万字符，超出后自动淘汰最久没用到的，不会无限变大。
- 设置面板里能看到当前缓存了多少段，**🧹 清空翻译缓存** 可以一键清空。

想确认「有没有重复发请求」：按 F12 打开控制台，翻译时会打印类似
`[dual-translate] 请求 google：本条共 12 段，缓存命中 9 段，本次发送 3 段（420 字符）`。

## 隐私与安全

- 仓库里**没有任何写死的 API Key**。Key 只能你自己在设置面板里填，保存在酒馆的本地设置里。
- 酒馆的设置文件（`settings.json`）里含有你的 Key，**不要把它分享给别人或提交到 GitHub**。仓库自带的 `.gitignore` 已经把 `settings.json`、`.env` 等排除了。
- 用 DeepSeek 时，被翻译的文本会发给 DeepSeek 的服务器；用谷歌时，文本会发给谷歌（浏览器直连，或经酒馆后端转发）。介意的话请自行取舍。

## 常见问题

**点了翻译没反应，或者提示「请先在设置里填写 DeepSeek 的 API Key」？**
翻译源是 DeepSeek 时必须填 Key。如果你选的是谷歌，但点的是输入框旁的按钮，那个按钮也需要 DeepSeek 的 Key。

**谷歌翻译提示「酒馆后端无法从谷歌取得译文」或「请求超时」，酒馆控制台里还有 `ETIMEDOUT`？**
这是酒馆后端连不上谷歌（后端不读系统代理）。把「谷歌连接方式」改成「自动」或「只用浏览器直连」，用浏览器自己的网络即可；也可以在酒馆 `config.yaml` 里配置 `requestProxy` 后重启酒馆。如果提示里写的是「浏览器直连」失败，则是这台设备本身访问不了谷歌，请检查梯子 / VPN，然后点「测试谷歌连接」确认；也可以先切回 DeepSeek 使用。

**手机 App 里「浏览器直连」不通？**
App 内置的 WebView 可能不走你的梯子，或限制了跨域请求。保持「自动」即可，直连不通时会自动改走酒馆后端。

**谷歌翻译提示 404？**
说明你当前的酒馆环境里没有 `/api/translate/google` 这个接口（只影响「酒馆后端」路线），请改用「只用浏览器直连」或 DeepSeek。

**提示「翻译请求超时」？**
网络太慢或服务没响应（DeepSeek 等 60 秒，谷歌浏览器直连等 15 秒、酒馆后端等 20 秒）。点译文位置的「重试」就行。

**谷歌翻译提示不认识某个语言？**
选「自定义目标语言」时，如果填的是不常见的语言名，请直接填谷歌的语言代码，比如 `fr`（法语）、`de`（德语）、`zh-TW`（繁体中文）。

**逐段对照时译文位置有点错位？**
译文是按段落顺序贴到原文后面的。如果消息里有列表、标题等被酒馆渲染成多个元素的内容，位置可能对不齐，这时把显示模式切到「整块翻译」就不会错位。

**升级以后以前的译文还在吗？**
2.x 版把译文存在聊天记录里。升级后，只要某条消息的段落数能对上，旧译文会自动导入新缓存，不会重新花钱翻译。如果你点过「清空翻译缓存」，就不会再导入旧译文了。

**「清除全部翻译」和「清空翻译缓存」有什么区别？**
前者只移除当前聊天里显示的译文和旧版保存在聊天记录里的译文；后者清空新版的缓存，之后再看译文需要重新请求翻译源。

**手机上有什么要注意的？**
- 设置面板的输入框和按钮已经放大到方便点按，窄屏不会横向溢出
- 译文里的长单词、长链接会自动换行
- 切到后台或关闭页面时，缓存会自动保存

## 从 2.x 升级

直接覆盖安装即可，已有的 API 地址、Key、模型、语言、显示模式等设置都会保留。新增的「翻译源」默认还是 DeepSeek，所以升级后用起来和以前一样，需要谷歌时再切换。

## 目录结构

```
dual-translate/
├── manifest.json     扩展清单
├── index.js          主程序（界面、事件、缓存接入）
├── style.css         样式（含手机适配）
├── lib/
│   ├── text.js       分段、哈希、Markdown 保护等纯文本工具
│   ├── cache.js      译文缓存（内存 + localStorage）
│   └── providers.js  DeepSeek / 谷歌两个翻译源
├── README.md
└── .gitignore
```

纯 JS + CSS，没有任何构建步骤和第三方依赖。
