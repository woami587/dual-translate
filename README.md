# dual-translate
给 [SillyTavern（酒馆）](https://github.com/SillyTavern/SillyTavern) 和 TauriTavern 用的翻译扩展：把 AI 的外文消息**逐段翻译成中文，译文贴在每段原文下面**，对照着看；输入框里还有一个按钮，可以把你写的中文翻成英语 / 日语再发出去。  - 两个翻译源，随时切换：**DeepSeek**（或其他 OpenAI 兼容接口）、**谷歌翻译**（不需要 API Key） - 译文带缓存：翻过的段落不会再花一次钱、再发一次请求，刷新页面也还在 - 手机和电脑都能用，设置面板和按钮针对触屏做了适配
